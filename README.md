# Universal Mobile Master

Advanced Android Device Manager & Backup Tool.

## Features
- Full Backup & Restore (Photos, Videos, Apps List)
- File Manager (Browse, Upload, Download)
- System Info (Battery, Model, Android Version)
- APK Installer
- Screen Mirroring Support (via scrcpy)

## How to Run
1. Connect Phone via USB.
2. Enable USB Debugging.
3. Run: `sudo python3 universal_mobile_master.py`

## Requirements
- Python 3
- ADB (`sudo apt install android-tools-adb`)
